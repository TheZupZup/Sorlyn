# Sorlyn Shield

This directory is reserved for Sorlyn Shield, the planned native protection and
ad-blocking layer for the browser.

It is currently a placeholder. No implementation exists yet.

The initial prototype is intended to provide network-level blocking, simple
filter-list support, a local allowlist, and a per-site disable option. Shield
work is scheduled for Phase 3 of the roadmap.
