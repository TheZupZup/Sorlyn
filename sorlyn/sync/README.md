# Sorlyn Sync

This directory is reserved for Sorlyn Sync, the planned optional, encrypted,
privacy-first synchronization system for the browser.

It is currently a placeholder. No implementation exists yet.

Sorlyn Sync is intended to be strictly opt-in, end-to-end encrypted, and
possibly self-hostable. It is the most exploratory item on the roadmap and is
scheduled for exploration in Phase 4.
