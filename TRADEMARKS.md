# Trademarks

This document explains how trademarks are handled in the Sorlyn project. It is
informational and is not legal advice.

## Mozilla and Firefox trademarks

Sorlyn is built on the Firefox open-source codebase. "Firefox" and "Mozilla",
together with their associated names and logos, are trademarks of the Mozilla
Foundation. **Those trademarks belong to Mozilla.**

The Mozilla Public License 2.0, under which the Firefox source code is released,
grants rights to the **source code** but does **not** grant any rights to use
Mozilla's or Firefox's trademarks, names, or logos. Because of this:

- Sorlyn does not use the Firefox or Mozilla names or logos as part of its own
  branding.
- Sorlyn is a distinct product with its own name and identity.
- References to "Firefox" or "Mozilla" in this repository are made solely for
  accurate attribution and description, to explain Sorlyn's origins and
  technical basis.

For Mozilla's own policies, see Mozilla's trademark and branding guidance at
<https://www.mozilla.org/foundation/trademarks/policy/>.

## The Sorlyn name

"Sorlyn", "Sorlyn Browser", "Sorlyn Shield", and "Sorlyn Sync" are names used by
this project to identify the browser and its components. The project uses these
names to maintain a clear identity that is separate from Mozilla and Firefox.

## No affiliation

Sorlyn is an independent open-source project. **Sorlyn is not affiliated with,
sponsored by, or endorsed by Mozilla.** Any use of Mozilla or Firefox marks in
this repository is nominative — that is, used only to refer to those products
accurately — and does not imply any partnership or endorsement.

## Distribution note

When distributing a browser derived from Firefox source code, Firefox branding
(names and logos) generally must be removed or replaced. Sorlyn's approach is to
build and ship under its own branding. The process for replacing visible product
naming is described in [`docs/BRANDING.md`](./docs/BRANDING.md) and is being done
carefully, minimally, and auditably.

## Questions

If you believe something in this repository misuses a trademark or is
attributed incorrectly, please open an issue so it can be corrected.
